Software Engineer Bertina Hosting · Apr 2026 – Present · Tehran, Iran

Bertina is an Iranian hosting provider (domains, shared hosting, VPS, email, SSL). I designed and built WHMCS Automation Engine: a FastAPI core, a PHP WHMCS addon, and a Markdown knowledge vault. It handles tickets in production. Draft replies go to staff for approval and never send on their own. Customer replies are in Persian.

  • The pipeline classifies the request, pulls the account, and drafts a Persian reply. A second model then checks every factual claim against that account. If verification fails twice, or the action is destructive, the ticket goes to a human.
  • Tool access is policy-as-code, default-deny. Four tiers: read, reply, async approval, in-person for suspend / terminate / refund. Approvals bind to a hash of the exact action shown.
  • All reads go through one parameterized SQL path into a 40 GB WHMCS database, with statement timeouts and least privilege grants. Writes go only through the WHMCS API. One unindexed scan took 43.8s; an online index cut it to 0.58s. CI rejects any new query that filters a growing table without an index.
  • Prompt-injection handling is structural, not filter-based: vault pages are trusted, ticket text is quarantined. A prompt inside a customer message cannot become an instruction.
  • The same core also runs Ask Agent, Rewrite Agent, and an approvals queue. Rewrite Agent restyles a support reply into house style and follows instructions, including inserting tutorials before support sends it. Ask Agent is an in-house chatbot that answers from prompts, live data, and the knowledge base, with tools for support work and data analysis for admins.
  • Support quality went up while manual work went down: the team no longer burns out on repetitive tickets and spends its time on the real hard problems. Every ticket builds a customer profile, so big customers and real disasters get prioritized correctly and the noise gets solved.
