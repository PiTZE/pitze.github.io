Software Engineer Bertina Hosting · Apr 2026 – Present · Tehran, Iran

Bertina is a hosting provider: domains, shared hosting, VPS, email, SSL. Its support team answers a steady stream of repetitive tickets in Persian. I designed and built the WHMCS Automation Engine, a FastAPI core, a PHP WHMCS addon and a Markdown knowledge vault, so staff review a draft instead of typing every answer. It runs on real tickets and only drafts. A person sends.

  • I first let a second model grade every draft. Against my own hand audit it agreed at kappa 0.07 and sent half the drafts back for another go, which is a coin flip with a bill. I replaced it with narrow code checks, each replayed on logged drafts before it was allowed to act, and one targeted redraft at most. Every path ends with a person.
  • The agent may touch what a default-deny policy file lists and nothing else. Reads are free, notes and status changes run directly, nameserver and password changes wait for approval, and suspend, terminate, cancel and refund only happen in person. An approval holds a hash of the exact arguments, so nobody can approve one thing and run another.
  • The database is 40 GB and I read it through one parameterized query function, with a LIMIT, a 10 second timeout and read-only grants per table. One unindexed scan took 43.8 seconds. An index made it 0.58, and a query-plan test in CI now rejects any tool query that can't use one, unless I've listed the scan on purpose.
  • Customer messages are text, never instructions, and the knowledge vault is the one channel the model trusts. Greeting and signature come from code. The customer's IP and any private key pasted into a ticket never reach a model. The same core also runs Ask Agent for staff questions and Rewrite for house style.

Amor Æternus private · in development An operating system you can walk into, and my love letter to video games. I'm building it as a platform of worlds. A world holds rooms, a room holds devices, and every device is a virtual computer running ÆOS, with its own shell, filesystem, init and a Lisp that runs on a bytecode machine or compiles to GDScript. die Vinci github.com/PiTZE/die-vinci A love letter to Antimatter Dimensions, and a gift. It's an incremental game about the solids Leonardo drew for Pacioli: nine dice in a chain, the tetrahedron makes ink, ink buys the next die, and every ten of a solid doubles it. It plays out the hours you were away and works offline as a PWA. A simulator plays a first run and prints where the time went, which is how I balance it. TypeScript, tested in headless Chrome. Live at leo.generis.ir. WISP github.com/PiTZE/wisp-harness My agent harness, in Common Lisp, and the Emacs idea taken seriously: one image that stays up for weeks while I reshape it live instead of rebuilding it. The loop calls the model, runs its tools and stops at ten steps. Five tools, a browser UI with no build step, a socket REPL, and a session that reaches outside its directory asks permission instead of dying. Argus github.com/PiTZE/Argus For CSV files too big to open politely. Drop them in a folder, convert them once, then search and query them from the browser. Ingest converts types and stores GZIP, a picker chooses columns, and it installs as a systemd service. PorTTY github.com/PiTZE/PorTTY A real terminal in a browser tab: open the URL and your shell is there, from any machine. One Go binary, your default shell or tmux for sessions that survive, Nerd Font rendering, PWA install and auto-reconnect.
